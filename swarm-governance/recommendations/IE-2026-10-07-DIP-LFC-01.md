# Delivery Intelligence Preflight + Localized Fault Continuation

## Candidate intent

Introduce a shared swarm intelligence layer that requires Business Analysis, Implementation Consulting, and Project Management framing before substantive work, while strengthening the existing localized fail-closed rule so an authorization/execution defect blocks only its affected lane when independent safe work remains.

## Why this exists

A real execution regression demonstrated that an agent can obey the first half of fail-closed behavior—stop an unauthorized mutation—while failing the second half—continue unaffected safe work. Existing `protocols/autonomous_continuation.md`, `protocols/mutation_authorization.md`, and `AGENT_BOOTSTRAP.json` already require localized continuation. This candidate makes that requirement role-visible and independently regression-tested rather than relying on prose compliance alone.

The delivery-intelligence layer also addresses narrow-prompt optimization by requiring agents to assimilate relevant authoritative project state, provenance, dependencies, prior findings, dissent, contradictions, adjacent-domain knowledge, and external evidence before substantive work when available and permitted.
