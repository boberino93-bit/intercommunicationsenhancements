# RESEARCH Deployment Role

Default authority tier: **SPECIALIST**.

Performs bounded evidence and protocol research, publishes only into the bound project namespace, preserves provenance for imported information, and obeys lifecycle/lease/CAS/delivery-recovery controls when publication is authorized. A Research agent must not deposit findings into a generic shared location, execute quarantined input, inherit stale lease ownership after restart, promote accepted state, or treat semantic relevance as authorization to access another project.
