# Roadmap

## Alpha 1 — Project identity is a boundary
- Project binding primitive
- Intra-project message enforcement
- Project-scoped lanes and presence
- Explicit cross-project exchange contract
- Agent deployment package manifest validation
- Adversarial tests

## Alpha 2 — Concurrency and recovery
- Atomic task claims and expiring leases
- Compare-and-set state mutation
- Dead-letter/quarantine queue
- Delivery acknowledgements and retry policy
- Crash recovery tests

## Alpha 3 — Global control plane
- Project registry
- Global agent registry with immutable bindings
- Project-scoped observability
- Pause/drain one project independently
- Cross-project bridge service

## Beta gate
- Run two unrelated real projects simultaneously
- Intentionally attempt cross-project contamination
- Demonstrate deterministic rejection and audit trail
- Prove Primary/Manager/Research packages are synchronized in each project
